# 三臂标注效率对照实验 · 操作协议（v1.1，2026-11-17）

> 目标：量化“模型预标注帮助人工节省了多少时间”，产出比赛核心证据。
> **v1.1 变更**：C 臂从“AL 排序”改为“禁用点提示”消融，与后端 `VALID_ARMS=(manual, assisted, noprompt)` 对齐；AL 排序不再进入三臂统计。

## 0. 与队友达成的口径

| 决策 | 结论 |
|---|---|
| C 臂测什么 | **点提示消融**（`noprompt`）：B6 预标注 + 人工编辑，但禁用点提示交互式精修。AL 排序留给 `m8_al.py` 的 4 策略 × 5 轮训练侧消融。 |
| 用哪批图 | **exp60 的 68 张 val 图**。后端 `AGROLABEL_DATA_ROOT` 指向全量 AL 包的 `dataset/`（内含 `images/val`）。严禁使用 `al_pool` 那 36 张 train 图。 |
| 臂怎么分 | 每张图**只进一个臂**；按 GT 宿主类交错轮转，保证同一类的两张图不落在同一臂。 |
| B/C 预标来源 | **实时调 `/api/predict`**，与前后端演示链路一致；`predictions_b6.json` 作为备份和离线 QA，不要求前端导入。 |
| 计时主口径 | 后端 ops 自动日志的 `elapsed_from_open_ms`（看图→提交）；`timing_sheet.csv` 仅作备份/交叉核对。 |

## 1. 实验材料（网盘包内）

| 文件 | 用途 |
|---|---|
| `images/`（68 张 val 图） | 三臂共用的标注对象，按 34 宿主类分层抽样（每类 2 张） |
| `gt_labels_val/` | GT（YOLO txt），**仅实验结束后评分用，标注时不得打开** |
| `predictions_b6.json` | B6 预标注备份；主流程用实时 API，此文件仅用于离线核对 |
| `manifest.json` | 图清单 + 每图唯一臂分配（`arm_backend` 字段） |
| `timing_sheet.csv` | 计时备份表，已按真实臂名填好；主口径仍以后端日志为准 |
| `classes.txt` | 34 类名称与 id 对照 |

## 2. 三臂定义

| 臂 | 后端臂名 | 起点 | 操作 |
|---|---|---|---|
| **A 纯人工** | `manual` | 空白画布 | 看图从零画多边形 + 选类别 + 提交 |
| **B 预标注+编辑** | `assisted` | 实时 B6 预标注 | 拖顶点 / 删除假阳性 / 补漏 / 改类；**点提示可用** → 提交 |
| **C 点提示消融** | `noprompt` | 同 B | 同 B，但**禁用点提示**（前端点提示按钮不可用）；量化交互式精修的独立贡献 |

AL 不确定性排序（前端「智能选样」）可作为演示截图/录屏，但**不进三臂对照表**——它改变的是“先标哪些图”，属于训练侧采样效率问题，已由 `m8_al.py` 的 random / entropy / tta / coreset 四策略消融覆盖。

## 3. 计时与操作记录

1. **主口径**：后端 `elapsed_from_open_ms`，从第一次看到该图到点击提交；`elapsed_ms` 作为“首个标注动作起算”的辅助口径。
2. `timing_sheet.csv` 只作备份；手填漏记、精度到秒且靠回忆，不与后端日志冲突时采信。
3. 每图提交前**不允许**查看 GT 或他人结果。
4. 编辑四分类由后端 ops 日志自动记录：新画 / 删实例 / 拖边界 / 改类别。
5. 剔除规则：预热 3 张、超 15 min 视为离开、MAD 离群；用 `backend/tools/human_stats.py --with-editcost` 直接出表。

## 4. 顺序与疲劳控制

- 建议顺序：B → A → C（先熟悉工具，再测纯人工，最后测无提示条件）。
- 每臂 22–23 张图；若分多天做，每天各臂至少 8 张，避免某臂集中在疲劳时段。
- 有第二名标注员时：每人三臂都做，取平均；禁止两名标注员看同一张图。

## 5. 评分（提交后由强哥侧统一计算）

- 每臂提交结果导出为 COCO json（或直接用系统导出）；
- 计算：实例级 IoU 匹配率、mask mAP50、编辑成本加权分
  （**realistic 口径：新画 1.0 / 删实例 0.15 / 改类别 0.15 / 拖边界 0.3 / 标为无目标 0.15**，
  与手册 §08 的 7.63 / 5.94 同口径）；
  敏感性分析用 `flat / lenient / proto`（`proto` 为协议 v1.0 旧稿近似等权值）。
- **效率比** = 臂A耗时 ÷ 臂B耗时；**提示贡献** = 臂C耗时 − 臂B耗时（若为正，说明点提示本身也省时间）。

## 6. 交付物（队友回传）

1. `out/annotations/<arm>/` 三臂标注结果（按后端臂名分目录）
2. `out/logs/ops_<arm>.csv` 操作日志与自动计时
3. `backend/tools/human_stats.py --with-editcost` 输出汇总表
4. `timing_sheet.csv`（备份，可留空或只填异常说明）
5. 操作录屏（可选但强烈建议，比赛演示直接用）
