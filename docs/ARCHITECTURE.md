# 架构设计与选型论证

## 1. 系统总览：两条路径

本系统把"预标注"拆成**离线路径**与**在线路径**两条，只有在线的轻模型需要随标注迭代：

```
[离线路径 · 一次性 · 可复现 · 不占推理时延]
  PlantVillage(无掩码) ──GrabCut粗框(54ms)──> SAM2.1-t 精修(86ms)
        └─> 3,471 张伪掩码(通过率 85.8%) ──> 预训练权重
                              │
                              ▼ 初始化权重
[在线路径 · 每轮迭代 · 含人工反馈 · 单张 24ms]
  未标注池 → ①预测 → ②打分选样(entropy/TTA/coreset) → ③人工修正(5.6 次/张) → ④增量微调 → 回到①
```

- **离线重模型（SAM2）**：只解决"PlantVillage 有类无名、无掩码"这一件 PlantSeg 真值帮不上的事，
  产出伪标签用于预训练初始化。它**不在推理主链路**里。
- **在线轻模型（YOLO11n-seg）**：真正服务预标注的模型，随标注数据增长而迭代。

## 2. 为什么不用 SAM + GroundingDINO 做零样本预标注

评审会问："既然 SAM2 + GroundingDINO 能零样本分割，为什么还要训练？"
我们用 PlantSeg 真实像素级真值做了实测，结论有数据支撑。

### 实测：同一批 40 张 PlantSeg test 图（174 个真实病斑）

| 指标 | 零样本 YOLO-World（开放词表代理） | 训练后 YOLO11n-seg |
|------|----------------------------------|--------------------|
| 逐图最高置信度中位数 | 0.0059（leaf 提示 0.0140） | 0.616 |
| conf=0.25 出框图占比 | **0 / 40（0%）** | 85.0% |
| 框落在病斑上的比例（conf=0.25） | 无可统计框 | 88.4% |
| 可输出类别数 | = 手写提示词条数（最多 5） | 34 |
| 单张时延 | 13–15 ms | 23–24 ms |

> 管线自检：同一套代码、同一个权重，在官方样例 `bus.jpg` 上给出 bus=0.909 / person=0.908，
> 说明零样本的低分不是配置错误，而是开放词表先验未覆盖近景病叶这一域。

### 四个理由（按对评分的杀伤力排序）

1. **主动学习 25 分会数学地归零（最致命）。** 零样本模型输出是 `f(图片, 提示词列表)`，
   与你标了多少张无关。模型不随标注更新，则"标注量 → 精度"曲线是水平线，
   `random / entropy / coreset` 的消融差异**恒等于 0**。这连带失去"同精度下修改次数降 30%"这一可证指标。
2. **类别命名有硬性上限。** 开放词表的"类别"= 你手写的提示词，不是可学习分类头。
   要覆盖 34（主机）/ 115（病害组合）个细粒度病名，只能把病名全塞进提示词再指望 CLIP 文本-图像匹配能分开——
   那已不叫零样本，且标错的类别**无法靠后续数据纠正**。直接冲击 18 分（精度与可用性）+ 12 分（细分类别）。
3. **可用性实测不达标。** conf 砍到 0.05 仅 2.5% 的图有框；砍到 0.001 才出 4.58 框/张且 48.6% 落在病斑上，
   但此时全是噪声，标注员要一框框删，比空着还费时。"框落在病斑上 ≠ 可用"。
4. **时延不是理由，须明说。** 零样本反而更快（14 ms）。**别用 300 ms 去论证零样本不行**，
   真正压死它的是第 1、2 条。

### 诚实的现场事实

本环境 `sam_gpu` 中 `transformers` 与 `huggingface-hub` 版本冲突，真 GroundingDINO 加载不了，
故用功能等价的 YOLO-World 作代理（同为文本提示驱动的开放词表检测器，同样不认识"苹果黑腐病"）。
GroundingDINO 通常更强，所以上述结论**不只依赖"检测不到"这一条**；第 1、2 条与具体检测器无关。

## 3. 仍待提升（评审会追问，先摆上）

- 训练后严格实例召回仅 **0.286**（mask mAP@0.5 = 0.2492）。
- 加权编辑 **5.609 次/张** 才略低于纯手工 **7.083**；换成等权则 9.587 反超手工，
  conf 从 0.10 扫到 0.80 也从未跨过 7.083。
- 结论："方向对、模型没训透"。计划：换 `yolo11s-seg` 或跑满 100 轮，并对高密度图做分块/SAHI 推理。
