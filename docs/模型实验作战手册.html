01 / 目标与已有证据

数据与标注审计→统一基线→模型创新与消融→人工修正实测→主动学习
评分重点

预标注质量 30 分
其中目标类别精度与可用性 18 分、细分类别/小样本 12 分。

任务语义

病斑区域分割
34 类是宿主植物；115 类为宿主—病害组合。连通域派生的伪实例需人工核验。

当前状态

SAM3 全量微调冒烟已跑通
正式 S2 成绩、LoRA 训练结果及交互精修收益均待核验。

项目文档记录 YOLO 的 0.0568、0.2492、0.287 等不同数值，来源及配置尚未统一；SAM3 旧提示实验记录 mAP50 0.0254，但提示与目标语义、评测协议均需重新核实。匹配实例 Dice 0.845 不能代表全部实例质量。所有数字先作为历史记录，不自动填入正式成绩表。

本手册为研究与执行计划。标有“假设 / 待测 / 占位”的内容均不是已取得的成绩；方案组合可大胆尝试，结论由数据决定。

03 / 固定评测口径

  • 统一：数据版本、类别映射、原图尺寸映射、匹配方法、评测代码版本与检测上限；验证集选模型、提示和阈值，测试集在方案锁定后用于最终评估。
  • 分开报告：单类病斑定位/分割；34 宿主分类与分割；115 细粒度任务。YOLO-World 框 AP 与掩码 AP 不混比。
  • 主指标：mask AP50、AP50–95、AP75、实例召回；按真值病斑面积分小/中/大，报告各组定义与数量。补充逐类 AP、漏检和误检。
  • 部署：硬件、输入尺寸、batch=1、预热、样本量、P50/P95、显存；端到端包括预处理、推理、精修和后处理。300 ms 是参考目标。
  • 提示协议分开：通用病斑；预测/用户提供类别；真实类别 oracle 上限。真值框仅用于分析精修上限。

05 / 创新路线：大胆假设，小心求证

I-01 · 推荐主线 / 针对小病斑

SAM3-LoRA + 全局—局部病斑感知训练

假设：小病斑在统一缩放时丢失细节；混合整图与包含病斑的局部裁剪，能同时保留上下文和细节，提高小病斑召回，减少漏画。

实现：先对 SAM3 部分注意力层插入 LoRA，确认可训练参数及梯度；整图与训练集病斑裁剪混合，裁剪保留周围上下文；推理用整图或无需真值的重叠切片，跨切片映射并去重。可先试 rank 8 / alpha 16，记录参数位置、比例和显存。

消融：零样本 → 固定提示 LoRA → + 局部训练 → + 非 oracle 切片；与全参数微调及 YOLO 分割对照。分别观察小目标召回、误检、AP 与耗时。若小目标无收益或重复预测抵消收益，停止该分支。

亮点表述：围绕农业病斑尺度分布设计的轻量适配与多尺度训练；属于可验证的组合/针对性创新，不预设学术首创。

I-02 · 推荐拓展 / 针对提示不稳定

提示鲁棒 LoRA：等价表达 + 负提示

假设：训练时使用经核验的病斑等价表达，模型能减少对单一措辞的敏感性；负查询有助区分不匹配类别。

实现：固定提示基线 → 每次随机抽一种语义等价提示 → 检查空目标查询未被过滤后加入确为不存在的负类别。评测未参与训练的表述、错误提示误响应；预测类别与真实类别 oracle 分开。

消融：固定 / 多提示 / 多提示+负提示；推理时固定单提示。若收益只是增加误检或多提示时延不划算，则回退。实例一致性损失是后续扩展，须先解决实例匹配。

I-03 · 工程组合 / 人机提效

轻量预标注 + 按需 SAM3 精修

假设：只对可能有边界问题的候选精修，可在时延预算内减少实际修边量。以 YOLOE/YOLO 分割结果或 YOLO-World 预测框为输入；模型分数和病斑尺寸是候选信号，需验证是否能识别质量问题。

消融：无精修 / 全量精修 / 按需精修；再比较常规 YOLO 与 YOLO-World 框。记录精修调用率、总体 AP、误检、P95、人工秒数。真值框仅作上限；交互分支需单独验证训练与推理路径。

I-04 · 细分类别 / 小样本

病斑定位与宿主—病害识别解耦

假设：通用病斑定位利用更多共享数据；结合局部病斑和整图上下文的分类可能改善少样本组合表现。

消融：34 宿主模型 / 直接 115 类 / 通用定位+上下文分类；分别报告定位质量、类别准确率与端到端指标，并处理缺类和样本不足。未知类别不强行输出可信结论。

已有 SAM3-LoRA、跨提示一致性与病害细节补偿相关研究；本项目强调可落地组合和场景适配，若形成论文需进一步检索相近工作。

06 / 按部就班执行

  1. 冻结数据与标签语义：清单、类别表、转换脚本、人工核查和数据权限。
  2. 跑 B0，形成可复现基线；建立 100–200 张固定验证子集用于冒烟，不替代完整验证集。
  3. 跑 B1–B3、Z1–Z3；固定输出与提示协议，挑最有价值的路线。
  4. 实现 LoRA 冒烟：确认实际训练参数、梯度、保存与恢复；再跑 I-01 固定提示对照。
  5. 加一种创新机制就做一组消融；先完整验证集决定是否保留，再锁定测试方案。
  6. 固定候选与接口：可选 YOLOE 直出、SAM3-LoRA 或按需精修；与队友开展人工编辑与耗时记录。
  7. 在预标注方案稳定后开展公平 AL；最后整理报告、演示和离线部署。
