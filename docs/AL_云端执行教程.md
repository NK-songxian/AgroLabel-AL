## 一、截图问题的诊断

队友那句话的意思：

1. **12GB 显存跑 @1280 bs8 大概率 OOM**——B6 训练时在 96G 卡上用了约 40GB 显存，12GB 的卡装不下这个 batch；
2. **降配（bs2/640）会破坏与 B6@1280 的可比性**——AL 消融的每一轮训练配置（imgsz、batch、epochs、增强）必须与全监督 B6 完全一致，否则"AL 曲线 vs 全监督参考线"的对比就不公平，评审可以直接质疑。

**解法**：不在队友机器上跑训练。AL 训练只在云端 96G 卡上做，队友拿到的是"该标注哪些图"的清单，人工标注完回传。这正是标准 pool-based AL 的人机分工。

## 二、主动学习是什么（比赛要求的口径）

### 2.1 一句话定义

> 用最少的标注量，把模型训到尽可能好——**模型自己挑"最值得标"的图**，而不是随机撒网。

### 2.2 闭环四步（每一轮都重复）

```text
① 初始化：每类随机选 3 张（共 ~102 张），人工标注（我们已有 GT，直接用）
        ↓
② 训练：用当前已标注集训 YOLO26x-seg @1280（配置与 B6 完全一致）
        ↓
③ 评估：在固定 test split（1560 张）上测 mask mAP50 —— 这是曲线上的一个点
        ↓
④ 选样：模型对剩余 ~5200 张未标注图打分，按策略选出下一批（~420 张）
   - random   ：随机选（对照组，证明"聪明选样"真的有用）
   - entropy  ：模型最拿不准的图（不确定性采样）
   - tta      ：翻转/多尺度后仍拿不准的图（更稳的不确定性）
   - coreset  ：既不确定又彼此不相似的图（兼顾多样性，避免选一堆重复图）
        ↓
   把选中的图"加入已标注集"（用 GT 当人工标注结果），回到 ②
```

### 2.3 比赛叙事：为什么这是核心证据

三臂实验回答"**预标注帮人工省了多少时间**"（标注侧效率）；
AL 消融回答"**聪明选样帮模型省了多少标注量**"（训练侧效率）。

两条曲线合起来才是完整主张：**预标注 + 主动学习 = 少标图 + 少改图**。

评审看的是：

- 4 条策略曲线在同一张图上，同预算下 entropy/coreset 是否压过 random；
- 全监督 B6（0.416，用全部 5367 张）作为右上角参考线；
- **达到同等 mAP，AL 策略比 random 少用多少标注量**——这是"减少标注量"的量化证据。

### 2.4 必须遵守的三条方法学红线

1. **起点绝不能用 B6**。B6 已看过全部 5367 张 train 图，用它做 AL 起点等于把训练数据泄露给选样器，曲线会虚高且平坦，证据作废。必须用官方 `weights/yolo26x-seg.pt`（没见过 PlantSeg 任何图）。
2. **所有策略共享同一批候选子集**（`--cand-mult 5`，每轮从池子的 5 倍预算里先粗筛），保证策略之间可比。
3. **训练配置逐轮固定**（epochs=25、imgsz=1280、batch=8、增强一致、val=False），唯一变量是"哪些图进了训练集"。

## 三、云端执行步骤（照抄即可）

### 3.1 环境确认（已就绪，无需操作）

- 数据：`/root/autodl-tmp/Ryan/ArgoLable-AL/data/plantseg34/`（train 5367 / val 846 / test 1560）
- 脚本：`src/m8_al.py`
- 官方冷启动权重：`weights/yolo26x-seg.pt`
- GPU：96G 卡，当前空闲

### 3.2 冒烟验证（~30 分钟，可跳过但建议跑）

之前已跑过 random 策略 3 轮冒烟（102→0.015、523→0.060、944→0.109），结果在 `runs/al_b6_smoke/`。无需重跑。

### 3.3 正式消融（后台挂起，约 10–14 小时）

```bash
cd /root/autodl-tmp/Ryan/ArgoLable-AL
nohup python src/m8_al.py \
  --data data/plantseg34/data.yaml \
  --strategies random entropy tta coreset \
  --rounds 5 \
  --init-per-class 3 \
  --budget-step 0.08 \
  --model weights/yolo26x-seg.pt \
  --epochs 25 --imgsz 1280 --batch 8 --device 0 \
  --cand-mult 5 \
  --work-root ./runtime/al_full \
  --name al_full_ablation \
  > runtime/logs/al_full_ablation.log 2>&1 &

# 看进度
tail -f runtime/logs/al_full_ablation.log
# 看 GPU
nvidia-smi
```

**时间预估**（基于冒烟外推）：

| 阶段 | 单轮 | 4 策略合计 |
|---|---|---|
| r0（102 张，15→25ep） | ~10 min | ~40 min |
| r3（~1400 张） | ~1.5 h | ~6 h |
| r5（~2200 张） | ~2.5 h | ~10 h |
| **总计** | — | **~12 h，一晚跑完** |

### 3.4 跑完后得到什么
