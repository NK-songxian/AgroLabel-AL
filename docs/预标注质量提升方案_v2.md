# 预标注质量提升方案 v2：在阴性证据之上做可证伪的三条路线

> 版本：v2.0，2026-11-18
> 适用：AgroLabel-AL，云端 RTX PRO 6000 96G，val 846 固定评测
> 原则：大胆假设、小心求证；每条路线都设 **go / no-go 门槛**，不达门槛即停。

---

## 0. 为什么现在“指标不高”——先校准预期

当前主线 B6（YOLO26x-seg@1280）在 val 上的实际数字：

| 指标 | 数值 | 口径 |
|---|---|---|
| Box mAP50 / mAP50-95 | 0.418 / 0.239 | Ultralytics val |
| Mask mAP50 / mAP50-95 | 0.416 / 0.214 | Ultralytics val |
| Mask mAP50 / mAP50-95 | 0.3521 / 0.1710 | 自写 COCOeval（与历史实验同口径） |

这不是“模型很弱”，而是任务本身难：34 宿主类、病斑尺度跨度大、实例由掩码连通域派生、Tomato/Cucumber 等视觉难类拖累宏平均。判断提升必须**同口径对比**，且不能只看 matched Dice——SAM3 零样本 Dice 曾达 0.845，但 mAP50 仅 0.025，属于严重误导性指标。

## 1. 已有阴性证据（决定方案边界，避免重复劳动）

| 已做实验 | 结果 | 结论 |
|---|---|---|
| SAM3 零样本（Z1/Z1s，34 类同时查询） | mAP50 0.0007–0.0102；病征短语约 14× 提升但仍近零 | 开放词汇文本提示不可用 |
| GT 宿主条件化提示 | mAP50 0.1709 | **泄露上界**，不可混比 |
| YOLO-World / YOLOE 零样本（Z2/Z3） | box 0.0038 / 0.0069，seg 0.0064；提示几乎无影响 | 开放词汇检测不可用 |
| SAM3 全参微调（F1） | 冒烟 mAP50 0.084，约 2h/epoch | 太慢，放弃迭代 |
| fastft_rival（冻结 SAM3 主干 + QV-LoRA r8，262K 参数） | 语义 mIoU 0.3234；实例 mAP50 0.120；139.7s/epoch（约 52× 加速） | LoRA 可行，但距 B6 0.352 仍差 0.23 |
| F4：GT 框 + SAM3 vs YOLO 框 + SAM3 | 0.844 vs 0.034 | **SAM3 框提示收益被检测器框质量锁死** |
| I-03：按需 SAM3 精修 | mAP50 0.0230→0.0240；人工时间 -2.6% | 常规预标注质量下收益微小 |
| I-04：115 类解耦 | 0.011–0.037 | 缺类严重，暂不可行 |
| C 线语义投票融合（两代） | B6 0.3521 → 融合 0.3258 | 端到端类别头优于语义投票 |
| M2F-v2 | segm mAP/mAP50 0.140/0.281 | 低于 B6，D 线关停 |

**推论**：单纯把“更大的视觉大模型 / 开放词汇”搬过来，在我们这个任务上已被多轮证伪。可继续推进的只有两类：①不依赖文本提示的**推理时多尺度增强**；②把 SAM3 用在**它真正擅长的边界精修**，且必须由 B6 提供高质量提示。

## 2. 三条路线与判定门槛

### 路线 A（最高优先级，无训练）：B6 + SAHI 切片 + TTA

针对截图里的核心假设——“小病斑在统一缩放时丢失细节”——用推理时切片验证，而不是先训 LoRA。

1. **SAHI 重叠切片**：1280 图块，重叠 25%，全图 + 切片一起推理，坐标映射回原图后按类别做 NMS（IoU 0.6）。
2. **TTA**：水平翻转 + 尺度 1.0/1.15，合并结果。
3. **组合**：SAHI + TTA。

| 判定项 | go 门槛 |
|---|---|
| val mask mAP50 | ≥ 基线 0.3521 **+0.02** |
| 小目标 AP | 提升 ≥ 5pt |
| P95 延迟 | ≤ 基线 2 倍（约 300ms/图） |

若不达延迟门槛但 mAP 有收益，则做成“难图精修模式”，只对低置信图启用，不进默认链路。

### 路线 B（研究赌注，窄化目标）：SAM3-LoRA 小目标增强

外部证据支持这一方向，但**不是我们的主线**：

- rootSAM3（IEEE MIPR 2026）：LoRA + 早期层细粒度特征与后期语义融合 + gated 机制 refine DETR encoder，单一框弱提示下小目标提升明显，代码开源（github.com/hfitriyah/rootSAM3）。
- 番茄温室合成数据（2026）：SAM3 最后 12 层 ViT qkv 上 LoRA + WiSE-FT(α=0.75)，真实果实 IoU +12.9pp；全参微调最优但代价高。

我们的做法必须避开已证伪的“文本提示直接出实例”：

- **B1（边界精修器）**：以 **B6 预测掩码**作为提示（不是框，不是文本），只精修边界模糊的候选；对比“无精修 / 全量精修 / 按需精修”。
  - go：ΔmAP50 ≥ +0.01，精修率 ≤ 30%，人工秒数下降 ≥ 10%。
  - no-go：复现 I-03 的 +0.001 或精修率 99%，立即停。
- **B2（全局—局部小目标模块）**：在 fastft_rival 的冻结主干 + QV-LoRA 上，加入 rootSAM3 式早/晚层门控融合；训练用整图 + 病斑中心裁剪（保留上下文），推理裁剪由 B6 预测定位，**非 oracle**。
  - 先跑 200 图 pilot、2 epoch、rank 8 / alpha 16；
  - go：pilot mask mAP50 ≥ 0.20 且小目标 AP +5pt；否则停止，不再扩全量。
  - 明确：即使成功，也优先作为 B6 的补充精修器，不切换主线。

### 路线 C（最可能稳定提升）：AL 选样 + B6 增量微调

1. 队友完成 4 策略 × 5 轮 AL 消融（官方 `yolo26x-seg.pt` 冷启动）。
2. 选胜出策略的高价值样本，对 B6@1280 做增量微调（30–50 epoch）。
3. 对 Tomato / Cucumber 等弱类过采样；必要时试 1600 分辨率（batch 降到 4）。
4. 目标：用 40–60% 标注量达到或超过当前全监督 B6。

这条路线不依赖大模型玄学，证据链最干净，且与比赛“主动学习”主题一致。

## 3. 统一评测口径（必须固定）

每次实验必须报告：

- Box mAP50 / mAP50-95；Mask mAP50 / mAP50-95（自写 COCOeval，val 846）；
- 小 / 中 / 大目标 AP；per-class AP，单列 Tomato、Cucumber；
- P50 / P95 延迟，显存峰值；
- 人工对照：中位秒/图、加权编辑成本、提交 IoU。

禁止：用 matched Dice 代替 AP；用 GT 条件化提示结果当正式成绩；用厂商倍数代替自有实验。

---

## 4. 执行顺序

1. **立刻**：路线 A，云端约 1–2h 可出结果，无需训练。
2. **等待队友**：AL 消融回传 → 路线 C 增量微调。
3. **并行低优先级**：路线 B1（B6 掩码提示 SAM3 精修），200 图 pilot。
4. **仅当 A/C 都停滞**：才启动 B2 全量训练；否则不消耗 96G 卡。

---

## 5. 结论性判断

- 我们对“SAM3-LoRA / 开放词汇能直接解决”的信心是**低的**，因为已有 6 组阴性证据。
- 我们对“切片推理提升小病斑召回 + AL 增量微调提升 B6”的信心是**高的**，因为前者直接针对尺度问题且无训练风险，后者已有 AL 冒烟曲线支撑。
- 截图中的 I-01 思路值得保留，但必须改造成“B6 提示 + 小目标模块 + 严格 no-go”的窄化版本，不能当成主线赌注。
